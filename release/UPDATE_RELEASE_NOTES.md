# Independent installation and updates

- Install with a latest-public, latest-beta or exact-version script, without an
  interactive prompt. Update All is optional. Launch from the main menu afterward.
- Browse public and early-access releases in Options > Updates, with release notes
  and download sizes. Public users choose whether to receive early-access notices.
- Enter a future beta's code before updating, or install it for browsing.
- Prepare an update while browsing and restart when ready. Saved access, sign-in
  and settings stay in place; rollback stays available from the Scripts menu in MiSTer Menu.
- Uninstall offline, keeping settings by default or explicitly removing Plex data.

Updates appear once a release and its catalogue are published.
