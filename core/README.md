# FPGA core

Display scanout, audio synchronization, input and overlay support for MisterZine
Plex Core. Includes the MiSTer framework and PLL sources required to compile.

See [build instructions](../docs/BUILD.md), [architecture](../docs/ARCHITECTURE.md)
and [licensing](LICENSING.md). Use the packaged launcher to start the core and
application together; loading an RBF alone does not launch the application.
