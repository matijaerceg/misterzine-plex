# MisterZine Plex Core

An independent Plex client for MiSTer FPGA, designed for browsing and watching
your library on a CRT. Supports controller navigation, search, playback controls,
NTSC 480i and HDMI 480p. Early alpha; a Plex account and a server capable of
transcoding are required.
